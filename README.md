# 스마트 평가 (SmartExam)

초등학교 선생님을 위한 AI 평가 도우미입니다.
단원평가(태블릿·지필 스캔) 자동 채점, 수행평가 AI 가채점, 관찰 기록, 교과 평어 초안, 나이스 입력 도우미를 한 프로그램에서 씁니다.

## 📥 내려받기 (로그인 필요 없음)

**👉 [SmartExam.exe 내려받기](https://github.com/buksori123-lab/smartexam/releases/latest/download/SmartExam.exe)** (약 160MB, 항상 최신 버전)

- 지난 버전과 바뀐 점: [버전 목록](https://github.com/buksori123-lab/smartexam/releases)
- 사용설명서는 교육청 홈페이지 게시글의 첨부 파일(docx)을 보세요.

## 설치와 첫 실행

1. `SmartExam.exe`를 받아 **D:\스마트평가** 같은 폴더를 하나 만들어 그 안에 넣습니다.
2. 두 번 눌러 켭니다.
   - 브라우저가 "자주 받는 파일이 아님" 경고를 띄우면 **[유지]·[계속]**을 누르세요.
   - 파란 **"Windows의 PC 보호"** 창이 뜨면 **[추가 정보] → [실행]**을 누르세요.
   - **방화벽** 창이 뜨면 **[허용]**을 누르세요. (학생 웨일북이 접속할 때 필요)
3. 교사 화면이 브라우저로 열립니다. 처음 비밀번호는 **1234**이고, 바로 새 비밀번호를 정합니다.
4. AI 연결 안내에서 AI 키를 넣습니다. 전북 선생님은 **교육청 AI(전북AI › API Gateway)** 키를 추천합니다.

## 꼭 알아 두세요

- 학생 기록·AI 키·비밀번호는 exe 옆 **data 폴더**에만 저장되고 인터넷에 올라가지 않습니다. 프로그램을 다른 선생님께 줄 때는 **exe만** 주세요.
- AI에는 학생 실명을 보내지 않습니다. AI 채점·평어는 초안이며, 최종 판단은 선생님이 합니다.
- 윈도우 10·11 PC에서 동작합니다. 학생은 웨일북·태블릿 브라우저로 접속하며 학생 기기에는 설치할 것이 없습니다.
- 새 버전으로 바꿀 때는 프로그램을 끄고(작업 표시줄 ✓ 아이콘 › 스마트 평가 끄기) 같은 폴더의 exe만 새 파일로 바꾸면 기록이 이어집니다.
